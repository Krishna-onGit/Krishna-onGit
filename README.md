### About Me

I started using AI to build back in 2022 — early enough that I can count myself among the first wave. My first real project was a **complete LinkedIn clone, end to end** — frontend, backend, database, all of it — built using nothing but a ChatGPT chat model as my pair programmer.

From there I went deep. Landing pages, web apps, booking systems, payment flows, custom frontends, secured databases, production-grade backends — not just writing code, but shipping systems that had to actually hold up.

Along the way, building end-to-end with AI as my primary tool freed up the time to understand what's *around* the code — business, users, legal compliance, governance, securities, scalability, DevOps, UX, and how customers actually think. That's what pulled me into **product management**.
